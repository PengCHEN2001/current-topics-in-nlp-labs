# Current Topics in NLP and Society — Labs

This repository contains lab assignments and experiments completed as part of the **Current Topics in NLP and Society** course in the **M2 Computational Linguistics** program at **Université Paris Cité** (2026–2027).

## Labs

### Lab 1 — Classification with LLMs

Explores different approaches to French word sense classification, comparing In-Context Learning (ICL) and Parameter-Efficient Fine-Tuning (LoRA/QLoRA), with a focus on experimental design and model evaluation.
